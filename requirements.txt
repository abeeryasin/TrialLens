# Pinned deliberately, on 2026-09-05, after a real incident.
#
# This file used to list bare package names. That means "install whatever is
# newest at build time", so one file produced three different stacks: this
# repo's venv (Python 3.9, streamlit 1.50, pandas 2.3) where the test suite
# actually runs; GitHub Actions, re-resolving on every scheduled run; and
# Render's first deploy, which resolved Python 3.14 with streamlit 1.63,
# pandas 3.0 and numpy 2.5. A passing suite therefore certified software
# that was not the software running in production, and any rebuild could
# change the deployment with no commit to point at.
#
# Every transitive dependency is pinned too, not just the seven direct ones:
# pandas and numpy arrive through streamlit, so pinning only the top level
# would have left exactly the drift that caused this.
#
# Regenerate deliberately, never casually:
#     .venv/bin/pip freeze   (then drop the dev-only entries, see
#                             requirements-dev.txt for what those are)
# and run the full suite before committing the result. The Python version
# itself is pinned in .python-version, which Render reads.
